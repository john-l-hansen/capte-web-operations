Outlook Setup Instructions

Step-by-step setup guides

For New Outlook on Windows and Outlook on the Web (outlook.office.com):

  1. Click the Copy signature button above.
  2. In Outlook, click the Settings gear icon (top-right) → Accounts → Signatures.
  3. Click + New signature, give it a name (e.g., Capte — New Email).
  4. Click inside the signature edit box and press Ctrl+V (or Cmd+V on Mac).
  5. Under Select default signatures, assign this signature to For New Messages.
  6. (Optional) Switch generator to Replies & Forwards, copy, create a second signature, and assign to For Replies/Forwards.
  7. Click Save.

For Classic Desktop Outlook for Windows (Word rendering engine):

  1. Click the Copy signature button above.
  2. In Outlook, go to File → Options → Mail → Signatures....
  3. Click New and enter a name (e.g., Capte Official).
  4. Click inside the Edit signature box and paste using Ctrl+V.
  5. Verify that the logo, spacing (22px indent), and contact rows align accurately.
  6. Under Choose default signature, select your account and set for New messages.
  7. Click OK to save.

For Microsoft Outlook on macOS:

  1. Click the Copy signature button above.
  2. In Outlook for Mac, go to Outlook menu → Settings... (or Cmd+,) → Signatures.
  3. Click the + button to add a new signature.
  4. Paste the copied signature directly into the preview area with Cmd+V.
  5. Set as default for your Capte email account.

For Outlook Mobile App (iOS & Android):

  1. Mobile email clients do not support complex nested HTML tables in local signature editors.
  2. Click the Copy plain text button above.
  3. In Outlook mobile, tap your profile avatar (top-left) → Settings gear → Signature.
  4. Paste the plain text signature into the signature field and save.

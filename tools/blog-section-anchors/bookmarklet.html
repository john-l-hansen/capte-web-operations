How to Pin the Capte Icon in your Chrome Toolbar:

  1. In Chrome, navigate to chrome://extensions in a new tab.
  2. Toggle on Developer mode in the top right.
  3. Click Load unpacked in the top left.
  4. Select the folder: tools/blog-section-anchors/chrome-extension/ from this repository.
  5. Click the puzzle piece icon in Chrome's top toolbar and Pin the Capte icon! Now you can click the Capte icon directly from your toolbar on any blog post!

● Mode: Default Zero-Config Engine (is.gd / v.gd)
🛠️ How to configure go.capte.co in Cloudflare & TinyURL
  1. TinyURL Dashboard: Go to TinyURL → Branded Domains → click Add Domain and enter go.capte.co.
  2. Cloudflare DNS: Add a CNAME record:
    • Name / Host: go (points to go.capte.co)
    • Target / Destination: custom.tinyurl.com
    • Proxy status: DNS Only (Grey cloud)
  3. Verify: Click Verify Domain inside TinyURL. Once green, all shortened links generated through this tool will use https://go.capte.co/xyz!

2 Option B: DevTools Console (For Technical Workflows)

Open the published blog post → Right Click → Inspect → Console → paste and run: 

(function() {
  const base = location.origin + location.pathname;
  const headings = [...(document.querySelector('article, .blog-post, .w-richtext, main') || document.body).querySelectorAll('h2, h3')];
  const idCounts = {};
  const lines = [];
  headings.forEach(h => {
    const text = (h.textContent || '').trim().replace(/\s+/g, ' ');
    const id = h.id ? h.id.trim() : '';
    if (!id) {
      lines.push(`⚠️ NO ID: ${text} — (no id assigned)`);
      return;
    }
    idCounts[id] = (idCounts[id] || 0) + 1;
    const prefix = idCounts[id] > 1 ? '⚠️ DUPLICATE: ' : '';
    lines.push(`${prefix}${text} — ${base}#${id}`);
  });
  const out = lines.join('\n');
  console.log(out);
  navigator.clipboard.writeText(out).then(() => console.log('✅ Copied to clipboard'));
})();

3 Known Limitations & Best Practices

⚠️ Heading Stability: IDs are dynamically calculated from heading text on page load. If an article's heading text is edited in Webflow CMS after links are shared, older anchor links will gracefully fall back to the top of the article. Pull section links only once an article's headings are final.
💡 Output Format: Output is formatted line-by-line as [heading] — [URL] for immediate copy-pasting into Notion, Slack, Google Docs, or social schedulers.

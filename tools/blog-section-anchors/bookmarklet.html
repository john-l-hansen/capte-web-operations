🛠️ How to configure go.capte.co in Cloudflare & TinyURL
  1. TinyURL Dashboard: Go to TinyURL → Branded Domains → click Add Domain and enter go.capte.co.
  2. Cloudflare DNS: Add a CNAME record:
    • Name / Host: go (points to go.capte.co)
    • Target / Destination: custom.tinyurl.com
    • Proxy status: DNS Only (Grey cloud)
  3. Verify: Click Verify Domain inside TinyURL. Once green, all shortened links generated through this tool will use https://go.capte.co/xyz!

1. Executive Summary & Business Mission

Capte Technologies engineers industrial IoT, smart telemetry, and precision positioning systems for transit agencies, municipal vehicle fleets, and industrial infrastructure across North America and Europe.

The Capte Design & Web Operations Portal is the central operational nervous system connecting brand design in Figma, version-controlled engineering in GitHub, live production in Webflow, and internal field tools for sales and marketing.

Strategic Convergence Intent: The explicit roadmap for all components, tools, and digital experiences across this repository is progressive migration and native integration into the primary Webflow site (capte.co) when able. All architecture and DOM structures are engineered for migration readiness into native Webflow elements, CMS bindings, and visual Code Components (@webflow/react).

2. Cross-Platform Source Authority

Operational authority is partitioned strictly across four primary systems:

Platform Authoritative Scope Carried into Production
Google Drive Business strategy, sales collateral requirements, legal and marketing copy. Approved doc URLs, stakeholder decisions, revision dates.
Figma Visual design intent, UI layouts, interactive component states, design tokens. Design system node URLs, responsive breakpoint specifications.
GitHub Implementation code, version history, CI/CD pipelines, token build outputs. Source of truth commit SHAs, PR reviews, release tags.
Webflow Live deployed production state, CMS collections, page templates, 301 redirects, and ultimate convergence destination. Published embeds, vanity routes, live runtime DOM.

3. Portal Inventory & Capabilities

Section A: Internal Marketing & Operations Utilities

  • Campaign Link & QR Generator (tools/campaign-qr-generator/): Eliminates "dead prints" and attribution loss. Automatically pairs physical marketing collateral (booths, banners, vehicle wraps, handouts) with Webflow 301 vanity routes (/go/[slug]) and forced UTM schemas. Features native Reed-Solomon error correction and exports high-DPI vector SVG and 300-DPI PNGs.
  • Blog Section-Anchor Extractor (tools/blog-section-anchors/): One-click bookmarklet enabling team members to extract deep anchor links (H2/H3 headers) from any live article on capte.co for precise social media threads and sales follow-ups.
  • Internal Email Signature Generator (tools/email-signature/): Word-engine-compliant Outlook email signature builder for Los Angeles, Versailles, and Amsterdam personnel with 1-click rich HTML and plain-text clipboard copy.

Section B: Active Web Components (Webflow Embeds)

  • Promo Card (components/promo-card/): Region-gated, campaign-driven promotional floating card (desktop) and bottom sheet (mobile) for industry event promotions. Utilizes Cloudflare same-origin /cdn-cgi/trace edge geo-detection with zero third-party tracking APIs or latency.
  • Dual-Delivery Architecture: Every web component is authored both as a visual React Code Component (with Webflow Designer properties) and as a self-contained vanilla HTML embed.

Section C: Codified Brand Design System & Tokens

  • 217 Codified Variables: Systematized colors, typography scales, spacing units, radii, and elevations.
  • Automated Daily CI/CD: Synced directly from Figma REST API via GitHub Actions into tokens.css and tokens.json.
  • Baseline Palette: Primary Deep Blue (#001384), Accent Blue (#093AEC), Accent Orange (#FC5522), Surface Tint (#F2F4FC).

4. Governance & Engineering Principles

Core Standard: All components adhere to the supreme laws in CONSTITUTION.md:
  • Strict CSS Scoping: Component-specific prefixes (e.g. .promo-card_*) prevent global styling collisions.
  • Fail-Closed Design: Components fail silently rather than showing broken UI states.
  • Zero Client Secrets & No Third-Party Trackers: First-party edge APIs only; zero API keys exposed in frontend code.

5. Change Management & Release Protocol

Mechanisms are versioned via Semantic Versioning in CHANGELOG.md. Live marketing campaigns (e.g., APTA Expo 2026) are tagged in Git upon publication:

git tag <component-name>-<campaign-id> # e.g., promo-card-apta-2026-transform-expo git push origin --tags

All active and historic campaign configurations are tracked in each component's campaigns.md ledger.
